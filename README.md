# IAM Interview Playbook

An interactive visual study guide built from `IAM_Engineer_Interview_Master_Playbook(1).md`.

## How to use it

Just open `index.html` in your browser — double-click the file. No server or
build step is required. The playbook content is embedded in `playbook-data.js`,
so all 292 topics load directly from disk.

The site includes searchable topic cards, category navigation, three mastery
levels, architecture flow diagrams, step-by-step sequences, study progress, and
light/dark themes.

## Study material

- `STUDY_GUIDE.md` — explanation of the topics with inline Mermaid diagrams.
- `IAM_Diagrams.drawio` — the same diagrams in editable draw.io form.

## Project files

| File | Purpose |
|---|---|
| `index.html` | Page structure |
| `styles.css` | Styling and themes |
| `app.js` | Parses the playbook and renders the UI |
| `playbook-data.js` | The playbook embedded for offline/file:// use |
| `IAM_Engineer_Interview_Master_Playbook(1).md` | Source content (292 topics) |
