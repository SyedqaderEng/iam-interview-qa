# IAM Interview Playbook

An interactive visual study guide built from `IAM_Engineer_Interview_Master_Playbook(1).md`.

Open the local site at `http://localhost:4173` while the preview server is running.

To start it from this workspace:

```bash
python3 -m http.server 4173
```

The site includes searchable topic cards, category navigation, three mastery levels, architecture flow diagrams, step-by-step sequences, study progress, and light/dark themes.
